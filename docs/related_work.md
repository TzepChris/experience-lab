# Related work

Background for this lab, not claims that Milestone A reproduces these papers.

- Sutton and Barto, *Reinforcement Learning: An Introduction*, planning-and-learning chapters. This project is model learning plus search in a tiny deterministic world, not a Dyna-Q replica.
- Gymnasium environment API: termination vs truncation. This repo uses a small compatible contract without depending on Gymnasium.
- Elahi et al., Adaptive Online Experimental Design for Causal Discovery (PMLR 2024): related adaptive-intervention theme, different assumptions.
- Kosoy et al., Learning Causal Overhypotheses through Exploration (PMLR 2022): related structured exploration work.
- One Life to Learn (ICLR 2026): broader symbolic world-model learning; our setting is finite, deterministic, and much smaller.

No research-gap claim is made in Milestone A.
